Eunoia Prime: Privacy Policy

Last updated: 11 November 2026

Eunoia Prime is a private, single-user application run by its owner on the owner's own computers. It is not a public service.

What data is accessed

With the owner's explicit consent (Google OAuth), the app accesses only the owner's own Google account data through:

  • Google Calendar API: to read and create calendar events.
  • Google Drive API: to store and sync appointment documents in a folder in the owner's Drive.

How data is used and stored

Data is used only to provide those functions to the owner. It is stored only on the owner's own devices and in the owner's own Google account. OAuth tokens are kept in a private, permission-restricted file on the owner's computer.

Sharing

Data is never sold, shared with, or transferred to any third party, and is not used for advertising or to train AI models.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data / revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
